# بسته افزونه استایل‌های اسکرین‌شات — Alireza Advanced Read More Elementor

## وضعیت پیاده‌سازی

این بسته **یک Add-on مستقل** است، نه ویرایش سورس اصلی افزونه. در درخواست فعلی فقط سه عکس وجود داشت و **ZIP/PHP/JS افزونه اصلی در اختیار نبود**. بنابراین نمی‌توان تطبیق نهایی نام ویجت، HTML واقعی دکمه و محتوای آن یا تست موتور Load More روی سایت را تأیید کرد. بسته قابل نصب است اما تطبیق با مارک‌آپ افزونه اصلی، در صورت متفاوت‌بودن نام کلاس‌ها، نیازمند بررسی سورس اصلی است.

در فایل‌های زمان اجرا فقط یک فایل PHP و یک CSS وجود دارد. **هیچ JavaScript جدیدی اضافه نشده**؛ هیچ محتوایی رندر مجدد، کوتاه، واکشی AJAX یا حذف نمی‌شود.

## نصب

1. پوشه `alireza-read-more-layout-pack` را در `wp-content/plugins/` قرار دهید، یا ZIP پوشه را از **افزونه‌ها > افزودن افزونه > بارگذاری** نصب کنید.
2. افزونه اصلی و Elementor باید فعال باشند. سپس **Alireza Read More — Screenshot Layout Pack** را فعال کنید.
3. در Elementor، ویجت **Alireza Advanced Read More** را باز کنید؛ در **Style > Screenshot Read More Layouts > Design Layout** استایل دلخواه را انتخاب کنید.
4. برای تطبیق پیکسل‌ها، مقدار ارتفاع نمای بسته / محدودیت متن را در **کنترل موجود افزونه اصلی** تنظیم کنید. این بسته آن کنترل را بازنویسی نمی‌کند.
5. پس از انتخاب، صفحه Elementor را یک بار ذخیره و پیش‌نمایش را مجدداً باز کنید. CSS صرفاً روی همان نمونه ویجت با کلاس انتخابی اثر می‌گذارد.

## اگر کنترل جدید دیده نشد

نام فنی ویجت Elementor را از متد `get_name()` در کلاس PHP افزونه اصلی بخوانید. در فایل `functions.php` قالب فرزند، این فیلتر را با نام واقعی جایگزین کنید:

```php
add_filter( 'aardm_layout_pack_widget_names', static function ( $names ) {
    $names[] = 'YOUR_ACTUAL_ELEMENTOR_WIDGET_SLUG';
    return $names;
} );
```

نام‌های رایج از پیش در PHP افزونه پشتیبانی می‌شوند. برای پیش‌فرض، به عمد ویجت‌های دیگر Elementor هدف قرار نمی‌گیرند.

## تطبیق HTML افزونه اصلی (بدون جایگزینی موتور)

برای تنظیم دقیق مکان دکمه و افکت Fade، در HTML موجود ویجت، این سه **کلاس مکمل** را روی المان‌های **موجود** اضافه کنید؛ هرگز المان یا دکمه جدید ایجاد نکنید:

- روی ظرف متن سروررندر: `aardm-content` (برای تست CSS الزامی نیست؛ برای تشخیص و تنظیم دقیق ارتفاع در موتور اصلی مفید است).
- روی ظرف دکمه: `aardm-actions` (مهم برای قرارگرفتن دکمه در پایین کارت؛ همچنین `aam-actions`, `aarm-actions`, `read-more-actions`, `[data-read-more-actions]` پشتیبانی می‌شوند).
- روی دکمه موجود: `aardm-toggle` (یا یکی از کلاس‌های مشابه در CSS؛ دکمه‌هایی که `aria-expanded` دارند نیز استایل می‌گیرند).

اسکلت صرفاً جهت نشان‌دادن محل کلاس‌های تکمیلی؛ **متن و تمام عناصر موجود اصلی باید همان‌طور باقی بمانند**:

```html
<div class="existing-content-class aardm-content" id="existing-unique-content-id">
    <!-- خروجی SEO واقعی از موتور رندر فعلی، بدون جابه‌جایی/بازنویسی -->
</div>
<div class="existing-actions-class aardm-actions">
    <button class="existing-toggle-class aardm-toggle"
            type="button" aria-expanded="false"
            aria-controls="existing-unique-content-id">+ مشاهده بیشتر</button>
</div>
```

`aria-expanded` باید **توسط موتور فعلی** هنگام باز/بسته‌شدن عوض شود؛ CSS به‌صورت خودکار محوشدگی را بر همین اساس برمی‌دارد. اگر موتور فعلی تنها کلاس دیگری به‌جز `aardm-is-expanded` استفاده می‌کند، سلکتور حالت باز را در CSS تطبیق دهید، نه با JavaScript تازه. شناسه‌های `aria-controls` باید برای هر نمونه یکتا باشند.

## معماری و محدوده تغییر

- کنترل select با hook رسمی Elementor اضافه می‌شود؛ `prefix_class` کلاس ظاهری را روی wrapper همان ویجت قرار می‌دهد.
- پیش‌فرض select تهی است؛ بنابراین تمام ویجت‌هایی که سبک انتخابی ندارند، هیچ استایل بسته را نمی‌گیرند.
- fade از pseudo-element و `pointer-events:none` استفاده می‌کند؛ محتوای SEO واقعی در DOM باقی می‌ماند.
- باز و بسته شدن، متن دکمه، وضعیت‌ها و انیمیشن ارتفاع: **همگی تحت مالکیت موتور افزونه اصلی** می‌مانند.
- فونت خارجی، jQuery، fetch/AJAX، DOM traversal، inline scripts و کپی engine اضافه نشده است.
- ریسپانسیو: 390px موبایل، 800px تبلت، 1440px دسکتاپ در fixture تست شده‌اند.

## محدودیت‌ها و الزامات تست نهایی

- آزمون‌های محلی با **fixture شبیه‌ساز مارک‌آپ** انجام شده‌اند؛ این به‌معنی تست روی افزونه فعلی کاربر یا سایت زنده نیست.
- بدون سورس اصلی نمی‌توان تضمین کرد نام get_name یا کلاس‌های دکمه/ظرف محتوا با پیش‌فرض این بسته مطابقت دارند، یا موتور اصلی `aria-expanded` را به‌روز می‌کند.
- از آنجا که انیمیشن واقعی و ارتفاع بسته در موتور اصلی تعریف شده، تطابق کامل حالات باز/بسته و SEO تنها پس از آزمایش با نسخه اصلی قابل تأیید است.

## تست‌های محلی

در پوشه `tests`، فایل `visual-fixture.html` شامل چهار نمونه (سه طرح و یک نمونه تکراری)، متن طولانی فارسی و اجزای semantic است. فایل `check_layouts.py` سه viewport را بررسی می‌کند (به‌علاوه نشان‌دادن/پنهان‌شدن gradient بر اساس `aria-expanded` و عدم تأثیر روی نمونه دوم). فایل `check_php.php` کنترل جدید، default بدون تغییر، و عدم دست‌کاری سایر ویجت‌ها را با mock ساده می‌سنجد.

```sh
php -l alireza-read-more-layout-pack.php
php -d zend.assertions=1 -d assert.exception=1 tests/check_php.php
cd tests && python check_layouts.py
```

تصاویر `preview-*.png` خروجی مرورگر از fixture هستند؛ نمونه نهایی سایت محسوب نمی‌شوند. منابع مرجع سه عکس آپلودشده کاربر است.
